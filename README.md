| รายวิชา | Database Management |

## โครงสร้างโปรเจค

```
buu-lost-found/
├── assets/css/         ไฟล์ CSS
├── config/
│   └── db.example.php  ตัวอย่างไฟล์เชื่อมต่อฐานข้อมูล
├── database/
│   └── setup.sql       สคริปต์สร้างตารางและข้อมูลเริ่มต้น
├── includes/           ไฟล์ PHP ที่ใช้ร่วมกัน
└── uploads/            รูปภาพที่ผู้ใช้อัปโหลด (ไม่ถูกเก็บใน Git)
```

## วิธีติดตั้ง

1. **นำเข้าฐานข้อมูล**
   - เปิด phpMyAdmin แล้วเลือกฐานข้อมูลของตัวเอง
   - ไปที่แท็บ **SQL** (หรือ **Import**) แล้วนำเข้าไฟล์ `database/setup.sql` จากนั้นกด **Go**
2. **ตั้งค่าการเชื่อมต่อฐานข้อมูล**
   - ก๊อปไฟล์ `config/db.example.php` แล้วเปลี่ยนชื่อเป็น `config/db.php`
   - แก้ค่า host, user, password และชื่อฐานข้อมูลใน `config/db.php` เป็นของตัวเอง
   - ไฟล์ `config/db.php` ถูก ignore ไว้ใน `.gitignore` จึงไม่ถูกขึ้น GitHub
3. วางโฟลเดอร์โปรเจคไว้บนเว็บเซิร์ฟเวอร์ที่รัน PHP ได้ แล้วเปิดผ่านเบราว์เซอร์
