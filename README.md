## ฟีเจอร์

- สมัครสมาชิก / Login ด้วยรหัสนิสิต / Logout
- **แยกประกาศตามคณะ** จากเลขหลักที่ 3-4 ของรหัสนิสิต (เช่น 68**16**0219 → คณะรหัส 16) ผู้ใช้เห็นและขอรับคืนได้เฉพาะประกาศที่คนในคณะเดียวกันโพสต์ ผู้ที่ยังไม่ Login จะเห็นเพียงหน้าแนะนำระบบ
- หน้าแรกแสดงประกาศของคณะตัวเอง ค้นหาจากชื่อของหรือสถานที่ และกรองตามหมวดหมู่ จุดรับคืน สถานะ
- หน้ารายละเอียด แสดงข้อมูลติดต่อหรือจุดรับคืน
- โพสต์ของที่พบ พร้อมรูปภาพ (JPG / PNG ไม่เกิน 2 MB) สถานที่ วันที่ และวิธีคืน
- แก้ไขและลบประกาศ ได้เฉพาะประกาศของตัวเอง
- ขอรับคืน → ยืนยันคืนเรียบร้อย หรือยกเลิกคำขอ (สถานะ ถูกพบ → รอรับคืน → คืนเรียบร้อย)
- หน้า "ประกาศของฉัน"

## ความปลอดภัย

| ความเสี่ยง | วิธีป้องกันในโค้ด |
|---|---|
| SQL Injection | Prepared Statement ทุก Query ที่รับค่าจากผู้ใช้ |
| รหัสผ่านรั่ว | `password_hash()` / `password_verify()` |
| Session Fixation | `session_regenerate_id(true)` หลัง Login |
| แก้ / ลบประกาศของคนอื่น | `AND user_id = ?` ใน WHERE ของ UPDATE / DELETE |
| ปลอมตัวตนผู้รับของ | ใช้ user_id จาก `$_SESSION` เท่านั้น |
| เปิดดู / ขอรับคืนประกาศของคณะอื่นโดยแก้ `?id=` | ใส่ `SUBSTRING(student_id, 3, 2) = ?` (รหัสคณะจาก Session) ใน WHERE ของหน้ารายละเอียดและการขอรับคืน |
| CSRF | CSRF Token ในทุกฟอร์มที่เปลี่ยนข้อมูล (รวมถึง Logout) |
| อัปโหลดไฟล์อันตราย | ตรวจเนื้อไฟล์ด้วย `getimagesize()` รับเฉพาะ JPG / PNG ≤ 2 MB และตั้งชื่อไฟล์ใหม่แบบสุ่ม |
| XSS | แสดงข้อความผู้ใช้ผ่าน `htmlspecialchars()` |

## วิธีติดตั้ง

1. **นำเข้าฐานข้อมูล**
   - เปิด phpMyAdmin แล้วเลือกฐานข้อมูลของตัวเอง
   - ไปที่แท็บ **SQL** (หรือ **Import**) แล้วนำเข้าไฟล์ `database/setup.sql` จากนั้นกด **Go**
2. **ตั้งค่าการเชื่อมต่อฐานข้อมูล**
   - ก๊อปไฟล์ `config/db.example.php` แล้วเปลี่ยนชื่อเป็น `config/db.php`
   - แก้ค่า host, user, password และชื่อฐานข้อมูลใน `config/db.php` เป็นของตัวเอง
   - ไฟล์ `config/db.php` ถูก ignore ไว้ใน `.gitignore` จึงไม่ถูกขึ้น GitHub
3. วางโฟลเดอร์โปรเจคไว้บนเว็บเซิร์ฟเวอร์ที่รัน PHP 7.0 ขึ้นไป (ต้องมี mysqli + mysqlnd) แล้วเปิดผ่านเบราว์เซอร์
4. ตั้งสิทธิ์โฟลเดอร์ `uploads/` ให้เว็บเซิร์ฟเวอร์เขียนไฟล์ได้ (เช่น 775 หรือ 777 แล้วแต่เซิร์ฟเวอร์) เพื่อให้อัปโหลดรูปได้
